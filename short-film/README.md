# Last Mutant Standing

*An unofficial MCU fan short film, about 20 minutes long.*

The Grandmaster gets hold of a stolen TVA TemPad and drags every Omega-level mutant in the
multiverse to Sakaar for one fight. Kamala Khan gets pulled in by clerical error and ends up
doing the commentary.

| File | What it is |
| --- | --- |
| [`last-mutant-standing.pdf`](last-mutant-standing.pdf) | The screenplay in standard format: 19 pages of story plus mid- and post-credits scenes (1 page ≈ 1 minute) |
| [`last-mutant-standing.fountain`](last-mutant-standing.fountain) | Plain-text source in [Fountain](https://fountain.io), which opens in Highland, Beat, Fade In and WriterSolo |

**Roster:** Jean Grey, Magneto, Professor X ("the machine rounded up"), Storm, Iceman,
Cassandra Nova, the Scarlet Witch and Franklin Richards. Kamala Khan comes along as the
clerical error.
